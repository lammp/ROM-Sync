Tools used to build and check the library.

SAK\      Switch Army Knife 0.7.14 - merges Switch base + update + DLC into one XCI/NSP (used for ROMs\switch)
nsz\      NSZ 4.x - decompresses .nsz Switch dumps back to .nsp (nsz-cli-windows-x64.exe is the command line, the gui folder the windowed version)
chdman\   chdman from MAME 0.289 - creates and verifies CHD disc images (psx, ps2, psp); "chdman verify -i file.chd"
